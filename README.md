# Equipo AZUL - Estructuras de Datos

Repositorio oficial del Equipo B / Azul enfocado en la implementación y desarrollo de estructuras de datos orientadas a objetos.

##  Descripción del Proyecto
Este proyecto contiene las soluciones y prácticas del equipo enfocadas en la materia de Estructuras de Datos, incluyendo el manejo de árboles, listas y colas de prioridad en C# (.NET 10).

##  Contenido del Repositorio
* **Árbol Binario de Búsqueda:** Implementación con integración de cola de prioridad (`Elihu Arbol`).
* **Listas Circulares:** Módulos de listas enlazadas circulares (`listaCircular.cs`).
* **Equipo B:** Carpeta con desarrollos y submódulos adicionales del equipo.

##  Tecnologías Utilizadas
* **Lenguaje:** C#
* **Framework:** .NET 10.0
* **IDE recomendado:** Visual Studio / Visual Studio Code

##  Cómo Ejecutar el Proyecto
1. Clona este repositorio:
   ```bash
   git clone https://github.com
   ```
2. Abre la carpeta del proyecto en tu IDE preferido.
3. Restaura las dependencias y ejecuta el proyecto:
   ```bash
   dotnet run
   ```
